# Contributing

> **Fork note:** this repository carries the MiniMax-M3.1-Flash EXL3 engine
> work. The upstream vLLM contribution process and CI do not apply here. Open
> an issue or a pull request against `exl3-mm31-flash`, and include the command
> you ran and the output you got.

The upstream vLLM contribution guide is at
[docs.vllm.ai](https://docs.vllm.ai/en/latest/contributing) and is a useful
reference for code style and testing conventions, but its sign-off and CI
requirements apply to the upstream project, not to this fork.
